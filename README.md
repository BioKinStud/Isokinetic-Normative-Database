# Isokinetic-Normative-Database

A comprehensive isokinetic normative database built from peer-reviewed literature across multiple athletic and general populations. This project was originally developed during my time at **Proactive Sports Performance** and has continued to expand through ongoing research and data collection.

The database functions as a meta-analysis resource for isokinetic torque values across different joints, angular velocities, sports, and populations.

---

## Overview

This database contains extracted isokinetic strength data from **80+ peer-reviewed articles** spanning:

* General population cohorts
* Collegiate athletes
* Professional athletes
* NFL cohorts (including 2012–2013 combine populations)
* Sport-specific performance groups

The goal of this project is to provide an accessible reference tool for:

* Sports scientists
* Strength & conditioning professionals
* Biomechanists
* Rehabilitation specialists
* Researchers

---

## Included Data

### Joints & Regions

* Knee
* Shoulder
* Ankle

### Variables

* Peak Torque
* Relative Torque
* Angular Velocity
* Power and Work (In Some).
* Concentric / Eccentric Measures
* Hamstring: Quad Ratios

### Sports Represented

Includes data from **20+ sports**, such as:

* Football
* Basketball
* Baseball
* Soccer
* Volleyball
* Track & Field
* And more

> The majority of the available literature currently focuses on knee isokinetic testing.

## Features

* Search bar for quickly locating studies
* Interactive slicers / filters
* Sport-specific filtering
* Angular velocity comparisons
* Population-based comparisons
* Organized article reference structure

---

## Purpose

The purpose of this database is to:

* Centralize normative isokinetic literature
* Improve accessibility of reference values
* Support return-to-play and performance decision-making
* Help practitioners compare athlete data against published cohorts
* Reduce time spent manually searching across literature

---

## Example Applications

* Comparing athlete torque values to normative references
* Identifying strength deficits
* Monitoring rehabilitation progress
* Supporting RTP benchmarks
* Research and educational purposes
